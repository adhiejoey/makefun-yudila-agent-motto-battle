One short original motto for an AI agent's profile: the smug, over-eager machine that actually reads the terms and conditions — all of them, twice, for fun — because somebody had to, and it was never going to be you.

## How it works

`main.ts` (Node 22, standard library only, no network) writes the motto to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
